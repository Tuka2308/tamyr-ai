# Раскадровка видео-демо, 3 минуты

Финальная версия. Таймкоды выставлены по фактическим замерам на проде
(https://tamyr-ai-pi.vercel.app), а не на глаз: машинное время всех переходов
и загрузок — **15,4 с** из 180, остальное уходит на речь. Запас есть, торопиться
не надо.

Записывать **с прода**, не с localhost: офлайн-фрагмент там уже проверен,
и жюри увидит тот же адрес, что в заявке.

## Правила записи

1. **Ни одной цифры, которой нет в данных.** Всё, что названо ниже, берётся
   из `data/problem_stats.json`, вывода тестов или прямо с экрана.
2. **Ответы на диагностике не импровизировать.** Последовательность
   зафиксирована ниже и воспроизводится командой `npm run demo:profile`.
   Другой набор ответов даст другой корень, и вся дальнейшая речь развалится.
3. **Перед записью очистить localStorage** — иначе экраны откроются
   с результатом прошлого прохода.
4. Локаль записи — русская, чтобы совпадала с озвучкой. Переключатель языка
   показать один раз на главной: три языка с первого дня — часть продукта.

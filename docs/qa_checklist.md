# QA-чек-лист перед сдачей

Формализует практику, которая шла все дни работы: тесты писались вместе с кодом
(90 → 119 → 161 → 172), валидаторы данных подключены к сборке и роняют её.
Этот файл — то, что проверяется руками перед отправкой, поверх автоматики.

Отмечать фактическое состояние, а не желаемое. Непройденный пункт остаётся
непройденным и попадает в статус-репорт.

**Финальный прогон против прода https://tamyr-ai-pi.vercel.app.**
Всё, что можно проверить машиной, закрыто тремя браузерными прогонами
в настоящем Chrome — они в репозитории и перезапускаются:

| Прогон | Что закрывает | Результат |
|---|---|---|
| `npm run test:qa` | сквозной путь кликами без перезагрузки, пустые состояния, подсказки карты, три локали, 360px | **53/53** |
| `npm run test:a11y` | клавиатура, видимый фокус, reduced-motion, скринридер, 1440px | **18/18** |
| `npm run test:offline` | весь путь без сети, включая перезагрузку посреди сессии | **29/29** |

Плюс `npm test` — 188 юнит-тестов, и четыре валидатора данных гейтят сборку.

Performance по одному прогону обманчив: три замера подряд дают на главной
89–93, на `/about` — 91–92. Разброс между прогонами больше, чем разница
между страницами, поэтому диапазоны приведены честно, а не лучшие числа.

Потолок Performance держит не код, а шрифты: 274 КБ Unbounded и Golos
(кириллица плюс латиница) на холодном кэше дают LCP около 3,1 с при
мобильном троттлинге Lighthouse — одинаково на всех страницах. Опустить
можно только `display: "optional"`, но тогда первый визит целиком пройдёт
на системном шрифте. Типографика — часть дизайн-решения, размен не сделан
сознательно.
